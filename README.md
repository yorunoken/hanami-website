# Hanami Web

The web application and API for the Hanami osu! ecosystem.

## Development

Install dependencies and start the frontend and server in development mode:

```bash
bun install
bun run dev
```

Useful checks:

```bash
bun run format:check
bun run lint
bun run typecheck
bun run test
bun run build
```
